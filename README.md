# Margherita Martorana

Personal research website built with Jekyll and deployed to GitHub Pages.

## Local preview

Install the dependencies from the `Gemfile`, then run:

```sh
bundle exec jekyll serve
```

The site is served locally at `http://localhost:4000`.

## Site content

- `index.html` and `_layouts/home.html` define the homepage.
- `_data/publications.yml` contains publication details.
- `about.md` contains the About page.
- `_data/menu.yml` defines the navigation.
- `_config.yml` contains site metadata and Jekyll settings.
